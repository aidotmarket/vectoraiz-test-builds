# vectorAIz test builds

Stage 1 test builds of the new vectorAIz desktop app, for testers only. Not for public use.

This repository holds only GitHub releases: installers, update archives and the updater manifest (`latest.json`). There is no source code here. The source is in [aidotmarket/vectoraiz](https://github.com/aidotmarket/vectoraiz), branch `native`. The Docker vectorAIz app and its releases stay in `aidotmarket/vectoraiz`.

Builds are unsigned (Windows) or ad-hoc signed (macOS); the install notes say how to open them. This repository is archived at the public release.
